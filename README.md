# Albania Now

**Finish the month. Meet the scientist.**

Albania Now is a free program for high-school students across Albania, run by
[Free Focus](https://santerre.ai), a nonprofit providing technology services to
nonprofits. It connects Albanian youth directly with working professors and
researchers.

**The model:** a sprint is four weeks of real material on one topic — optional,
outside the normal curriculum, delivered in English. One lesson a week: video
lectures, an audio brief, interactive reading, a Colab notebook, optional
go-deeper material, a quick check, and a build turned in to a teacher. Every
student who completes all four builds joins a **live video lecture by the
sprint's scientist**, recorded and posted afterward. Milestones earn stickers,
by mail. Each sprint has a Discord channel.

## What runs it

Plain static pages plus Google Colab's free tier. No platform, no licenses, no
student accounts. A school needs one thing: a teacher willing to collect weekly
turn-ins and confirm completions.

The material extends **Chicago First**, a ten-course AI and programming
curriculum built for Chicago high-school students
([chicago-hs-ai](https://github.com/johnsanterre/chicago-hs-ai)).

## Repo layout

- `index.html` — the program page; `sprint-*.html` — one page per sprint
- `lesson-<sprint>-<week>.html` — the lessons (generated by `tools/build_lessons*.py`,
  ported from Chicago First by `tools/port_lessons.py`)
- `notebooks/` — the Colab notebooks (generated by `tools/build_notebooks*.py`)
- `audio/`, `video/` — narrations and animated lecture videos
  (`tools/audio_sprints*.py`, `tools/videos_sprints*.py`, Kokoro + Pillow + ffmpeg)
- `deck.html` — the five-page program deck
